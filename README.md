### DQN in Reinforcement Learning

- This project focuses on implementing a Deep Q Network, specifically on Atari games
- Currently it supports the Cartpole and image based games

- The [*DQN-Agent.py*](DeepQN-RL/DQN-Agent.py), has the basic neural network architectures for both
- The [*DQN.py*](DeepQN-RL/DQN.py), has the Algorithm used in [Plating Atari with Deep Reinforcement Learning](https://arxiv.org/abs/1312.5602)
- To figure how to use the environment, you can refer to [*test.py*](DeepQN-RL/test.py)

- Future work:
  - I plan on adding support to many games in the future, like Mario
  - This work is a stepping stone for learning RL Algorithms, and i hope to add more algorithms
  - The end goal is to maintain a single agent, that can access multiple policies
  - Another work that can be inspired from this is Game Generation using Diffsuion Models, which is my current project
